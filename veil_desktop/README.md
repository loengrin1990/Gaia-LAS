# Вуаль — отдельная локальная утилита

Это самостоятельная копия текстового Veil. Она не запускает Gaia, не читает её
хранилище и не изменяет файлы исходного модуля. Результат — текстовая копия
без форматирования. Приложение предназначено для ручной обработки текста и
отдельных файлов TXT, MD, PDF и DOCX. Управляемые материалы и запрет экспорта
внутри Gaia остаются под правилами Gaia; это приложение не является способом
обхода их подтверждения.

## Установка для коллег

1. Установите [Ollama](https://ollama.com/download) для своей операционной
   системы и запустите его. Для работы одних только правил Ollama не нужен:
   снимите отметку «Дополнительно проверить локальной моделью».
2. Откройте Terminal на macOS или PowerShell на Windows и один раз выполните
   `ollama pull qwen3.5:9b`. Для модели понадобится несколько гигабайт диска.
3. Получите архив **Veil-macOS-Apple-Silicon.zip**,
   **Veil-macOS-Intel.zip** или **Veil-Windows.zip** от сборщика — в зависимости
   от компьютера.
   На macOS распакуйте архив и перенесите `Veil.app` в «Программы». На Windows
   распакуйте архив в папку и откройте `Veil.exe`. Python и Gaia на компьютере
   коллеги не нужны.
4. Вставьте текст или нажмите «Открыть файл», затем «Очистить и проверить».
   Сверьте полноту извлечённого текста и внимательно просмотрите очищенный
   результат. После этого поставьте отметку под результатом и сохраните
   текстовую копию или скопируйте её. Исходный файл приложение не изменяет.

PDF со сканами и текст внутри изображений не распознаются. Если из PDF или
DOCX не извлечён текст, приложение не создаст результат. Если часть страниц
PDF не содержала извлекаемого текста, приложение сообщит об этом. Даже после
успешной автоматической проверки результат нужно просмотреть вручную:
маскирование по правилам и модель не гарантируют нахождение всех данных.
Коммерчески чувствительные сведения не входят в гарантированный объём
проверки персональных данных.

## Остановка модели

После дополнительной проверки приложение просит Ollama выгрузить модель из
памяти. Чтобы сделать это вручную, нажмите «Остановить модель» в приложении
или выполните в Terminal/PowerShell:

```text
ollama stop qwen3.5:9b
ollama ps
```

Первая команда останавливает именно модель, вторая показывает загруженные
модели. Сервис Ollama и другие модели продолжают работать. Закрытие «Вуали»
само по себе не удаляет модель с диска.

## Сборка установочных архивов

Сборка выполняется на каждой целевой системе: упаковщик Python не создаёт
Windows-приложение на macOS. Нужны Python 3.11 и доступ к PyPI для установки
зависимостей сборки. Исходный код приложения не зависит от Gaia.

macOS:

```zsh
cd veil_desktop
zsh build_macos.sh
```

Windows PowerShell:

```powershell
cd veil_desktop
powershell -ExecutionPolicy Bypass -File .\build_windows.ps1
```

Сценарии создают архивы в `veil_desktop/dist/`. Сборка для обеих систем также
запускается в GitHub Actions при отправке ветки `codex/veil-desktop`; её можно
запустить повторно вручную как «Build standalone Veil». Для macOS с Intel нужен отдельный запуск
сборки на Intel; локальная сборка Apple Silicon предназначена для этого
процессора. Приложение может требовать версию macOS не старше системы, на
которой его собрали. Поэтому перед передачей коллегам используйте сборку
на macOS 15 из подготовленного сценария и проверьте запуск на целевой версии.

Сейчас сборки не подписаны. Для беспрепятственной установки коллегам нужны
подпись и нотариальное заверение macOS-приложения, а для Windows — подпись
исполняемого файла. Без этого системы могут показать предупреждение о
неизвестном разработчике. Подписывайте только проверенные финальные сборки.

## Граница данных

Текст обрабатывается в памяти приложения. Дополнительная проверка посылает
**только уже очищенный текст** в локальный Ollama на `127.0.0.1:11434`; внешние
адреса не используются. Приложение не сохраняет исходный текст и отчёты.
Результат записывается только по явному действию пользователя. Буфер обмена
может быть доступен другим приложениям.
