# Инструкции агенту

`agent_instruction` покрывает `AGENTS.md`, skills и другие правила работы агента. Эти документы описывают процесс исполнения и не заменяют product, architecture или safety contracts.

При изменении инструкции сохраняй существующую терминологию Gaia, не добавляй Claude-specific paths, hooks или configuration и не расширяй scope процесса без явного поручения.
