# Справочный документ

`reference` описывает фактически существующие компоненты, API, форматы, runtime или configuration. Обычно он имеет authority `descriptive`, но это не автоматическое правило: authority всегда задаётся явно в карте документов.

При sync сначала докажи изменение по implementation/config/runtime, затем обновляй только соответствующее reference-описание. Если доказательств недостаточно, результат — `AMBIGUOUS`.
