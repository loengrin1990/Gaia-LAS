# Результаты верификации

- `CONFIRMED` — документ подтверждён актуальными источниками.
- `DOC_DRIFT` — descriptive документация расходится с доказанным текущим состоянием и может быть синхронизирована.
- `UNDOCUMENTED` — существенное существующее поведение не отражено там, где должно быть описано.
- `STALE` — материал больше не относится к текущему состоянию, но ошибочно выглядит актуальным.
- `CONTRACT_VIOLATION` — implementation, config или runtime нарушает normative rule; не переписывай normative документ под это нарушение.
- `HANDOFF_DRIFT` — current development state/handoff не соответствует фактическому Git, runtime или stable workflow.
- `AMBIGUOUS` — доказательств недостаточно; не угадывай.

Результат должен указывать проверенные источники, scope, authority и следующий безопасный шаг. `CONTRACT_VIOLATION` требует явного архитектурного решения; `AMBIGUOUS` требует дополнительного доказательства.
