# Операционные инструкции

`runbook` описывает воспроизводимую процедуру: запуск, диагностику, восстановление или проверку. Его обычный authority — `operational` либо `descriptive` согласно фактической карте документов.

Проверяй шаги по реальным командам и текущим источникам. Не меняй runbook только потому, что более удобная процедура кажется предпочтительной.
