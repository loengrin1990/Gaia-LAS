# Решения и анализ

`decision_analysis` покрывает ADR, принятые решения, trade-offs, rationale и исторический анализ. Обычно это `historical` authority.

Новая реализация не отменяет старое решение задним числом. Если нужно изменить направление, требуется новое явное решение в его canonical home, а не переписывание истории.
